# نوتس: دليل المجلدات

| المجلد | فيه |
|---|---|
| `app/` | تطبيق Flutter |
| `design/` | مراجع التصميم |
| `tools/cook/` | أداة الطبخ: PDF + نص ← كتاب مترابط (راجع `tools/cook/README.md`) |
| `tools/batch/` | طبخ كتب مساحة حرة دفعةً واحدة، وخادم المراقبة وموقعها |
| `tools/publisher/` | نشر الكتب في مكتبة التطبيق |
| `tools/server/` | واجهة السيرفر التي يكلّمها التطبيق |
| `tools/perf/` | قياس السرعة على الجوال |
| `tools/*.py` | سكربتات فحص ومطابقة قديمة (كل واحد لمرة) |
| `scripts/` | سكربتات ومشغّلات مكتبة الحكمة: التصدير إلى docx، والمطابقة، والتنزيل، وإصلاح القاعدة |
| `samples/` | ملفات للتجربة (الأمالي) |
| `notes/` | ملاحظات |
| `archive/` | أرشيف (rar وملفات متفرقة)، وفي `_tidy-2026-11-13/` سجلّ هذا الترتيب وسكربت التراجع عنه |

## يبقى في الجذر عمدًا

الأدوات تفتح هذه بمساراتها، وفي التقارير مساراتها مكتوبة، فنقلها يكسرها:

- قواعد البيانات: `alhikmeh.db` و`alhikmeh_repaired.db` و`library.db`، و`matching_database.json`
- التقارير `*.xlsx` و`export_progress.txt` و`استوديو_مطابقة_كتب_PDF.html`
- مجلدات الكتب: `كتب_*` و`كتب مساحة حرة` و`مجلدات_pdf` و`pdf` و`جيد` و`des` و`نوتس`
- نواتج البناء: `build` و`_apk`، والكاش `.cache_ketab`

لنقل أي منها: غيّر مساره في الأدوات التي تفتحه أولًا (`grep` باسمه).
