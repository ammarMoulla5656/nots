# رفع الكتب إلى مكتبة نوتس

برنامج بسيط لنشر الكتب وتعديلها وحذفها. ما يُنشر يظهر في خانة «تحميل» داخل التطبيق.

## التشغيل

```
pip install -r requirements.txt
python publish.py
```

أو افتح `publish.bat`. عند أول تشغيل يطلب بيانات السيرفر، وتُحفظ في جهازك في
`%APPDATA%\nots-publisher\config.json`، وليس في المشروع ولا في التطبيق.

## نشر كتاب

1. **كتاب جديد**، ثم اكتب معلوماته. اسم الكتاب وحده إجباري.
2. **اختيار صورة**: تُصغَّر وتُحوَّل إلى JPEG تلقائياً.
3. اختر **كتاب مفرد** أو **عدة أجزاء**.
   - المفرد: ملف واحد، ويظهر في التطبيق زر تحميل واحد.
   - الأجزاء: أضف ملفات الأجزاء ورتّبها، وحدد **عدد الأجزاء الكلي**. يمكن أن ترفع
     بعضها الآن، فيظهر في التطبيق «متوفر 3 من 8 أجزاء». في التطبيق يختار المستخدم
     أي جزء، أو «تحميل كل الأجزاء».
4. راجع **ما يدعمه الملف**: يكتشفه البرنامج من كل ملف، ويمكنك تعديله.
5. **نشر الكتاب**.

للتعديل اختر الكتاب من القائمة، غيّر ما تريد، ثم **حفظ التعديلات**. الأجزاء التي
لم تتغير لا تُرفع من جديد.

## الصيغ وما يظهر للمستخدم

| ما يظهر | متى يكون مفعلاً |
|---|---|
| الكتابة بالقلم | دائماً |
| بحث، تعليم الكلمات، نسخ النص | في الملف نص حقيقي (لا صور فقط) |
| فهرس | في الملف فهرس، أو هو من مخرجات `nots-cook` |
| نص مصحَّح | الملف من مخرجات `nots-cook` |

يقبل البرنامج ملفات `.pdf` وحزم `.nots`.

## على السيرفر

كل ما يخص نوتس داخل مجلد واحد، ولا يكتب البرنامج ولا يحذف خارجه:

```
publiclibdata/nots/
  catalog.txt        الفهرس الذي يقرؤه التطبيق
  catalog.bak.txt    النسخة السابقة منه
  covers/            الصور
  books/<id>/        ملفات الكتب
```

بقية الملفات في `publiclibdata` (`api.php` و`core` و`data`) تخص تطبيقاً آخر يعمل
الآن. يمنع `_safe` في [server.py](nots_publisher/server.py) أي مسار خارج `nots/`.

الفهرس بامتداد `.txt` لأن ملف `.htaccess` في الجذر يحجب `.json` عن الويب.

ترفع الملفات أولاً ثم الفهرس، فلا يعرض التطبيق ملفاً لم يكتمل. والاتصال مشفر (FTP
عبر TLS). التطبيق نفسه يقرأ عبر HTTPS فقط ولا يحمل بيانات الدخول.
