# nots-cook: كتاب مترابط في ملف PDF واحد

يأخذ ملف PDF الكتاب وملف Word (أو نصّ) للكتاب نفسه، ويُخرج **ملف PDF واحداً**:

- يُرسَم كما هو تماماً، صفحةً بصفحة وبكسلاً ببكسل (يُتحقَّق من ذلك آلياً).
- طبقة نصّ صحيحة: النسخ والبحث في أي قارئ PDF يعطيان النص الحقيقي لا الرموز المشوّهة.
- فهرس (علامات PDF) من عناوين ملف Word.
- **خريطة الكلمات**: كل كلمة من نص Word مربوطة بمكانها في الصفحة ولها رقم ثابت في الكتاب.
  تطبيق نوتس يقرؤها تلقائياً: البحث يظلّل الكلمة في مكانها، والنسخ والتحديد والعلامات من النص نفسه.
  وصفها الكامل (لتطبيق الحكمة وغيره) في [FORMAT.md](FORMAT.md).

## الاستعمال

```
python cook.py "الكتاب.pdf"                 # يجد ملف Word المجاور تلقائياً
python cook.py "الكتاب.pdf" --text "النص.docx"
python cook.py مجلد\الكتب                    # كل ملفات PDF في المجلد
```

أو اسحب ملف PDF (أو مجلداً) وأفلته على `cook.bat`.

الناتج بجانب الأصل: `الكتاب.nots.pdf` وتقرير `الكتاب.nots.report.json`.
خيارات: `--debug-pages 21,100` يرسم مربعات الكلمات على تلك الصفحات في صور PNG للمراجعة بالعين،
`--ocr off` لإيقاف القراءة الضوئية، `--no-check` لتخطي الفحص.

المتطلبات: Python 3.10+ و `pip install -r requirements.txt`.

## كيف يعمل

1. **الحروف من الخطوط نفسها**: Word يكتب جدول ToUnicode خاطئاً للخطوط العربية فيخرج النص مشوّهاً،
   لكن الخط المضمّن يعرف كل شكل: جدول cmap للحروف، وجدول GSUB للأشكال (أول/وسط/آخر الكلمة) والحروف المركّبة (لا، لله...).
2. **المطابقة مع نص Word** صفحةً بصفحة على مستوى الحروف؛ ما تخالف فيه الخطوطُ النصَّ بوضوح يُتعلَّم ويُصحَّح (مثل خط Sultan bold).
3. **مكان كل كلمة** من مكان حروفها في الصفحة.
4. **الصفحات المصوّرة** تُقرأ بالقراءة الضوئية (Tesseract المدمج في MuPDF، تُنزَّل بيانات العربية مرة واحدة)،
   وتُستعمل فقط إذا طابقت النص بما يكفي.
5. **الكتابة**: لا يُمسّ شيء مما يُرسم؛ تُستبدل جداول ToUnicode فقط، ويُضاف الفهرس والمرفق.
6. **الفحص**: رسم كل الصفحات قبل وبعد ومقارنتها، وقياس طبقة النص في PDFium (محرك التطبيق) مقابل نص Word،
   وقراءة الخريطة من الملف كما يقرؤها التطبيق والتأكد أن PDFium يجد حروف كل كلمة داخل مربعها.

## النتيجة على «المسائل المنتخبة»

| | |
|---|---|
| الحجم | 4.97 MB (الأصل 4.90 MB) |
| الرسم | 544/544 صفحة مطابقة تماماً |
| الكلمات | 109,161 كلمة، 99.74% في أماكنها (الباقي صفحات مصوّرة) |
| مطابقة الحروف مع Word | 99.81% (الباقي فروق حقيقية في الطبعة المنقحة) |
| طبقة النص في PDFium | 30% ← 90.5% |
| المربعات التي أكّدها PDFium | 99.85% |

حدود معروفة: آيات القرآن المكتوبة بخطوط مصحف المدينة (QCF) في 4 صفحات مكانها تقريبي؛
والصفحات المصوّرة (الغلاف، الإجازة بخط اليد، البسملة) نصّها موجود للبحث بلا مكان دقيق.
النسخ في القارئات الأخرى قد يقدّم الشدّة على حرفها أحياناً (طريقة Word في رسم الحركات)؛ داخل نوتس النسخ من نص Word نفسه.
